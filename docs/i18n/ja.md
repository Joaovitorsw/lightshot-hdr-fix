# Lightshot HDR Fix

[English](../../README.md) · [Português (Brasil)](pt-BR.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md) · [简体中文](zh-CN.md) · [日本語](ja.md)

![HDR はオンのまま。スクリーンショットは SDR で。](../assets/hero.svg)

**HDR はオンのまま。スクリーンショットは SDR で。** FP16 キャプチャと GPU トーンマッピングで、Lightshot の白っぽい、または露出過多の画像を改善します。SDR 画像を使い慣れたエディターに渡し、Windows Graphics Capture の黄色い枠は追加しません。

[**Windows インストーラーをダウンロード**](https://github.com/Joaovitorsw/lightshot-hdr-fix/releases/latest/download/Lightshot-HDR-Fix-Setup.exe) · [リリース一覧](https://github.com/Joaovitorsw/lightshot-hdr-fix/releases) · [検証記録](../VALIDATION.md)

## インストール

1. まず[対応する Lightshot のオリジナル版](https://app.prntscr.com/en/)をインストールします。
2. **Lightshot-HDR-Fix-Setup.exe** をダウンロードして実行します。Python と管理者権限は不要です。
3. 対応版を自動検出します。見つからない場合はバージョンフォルダーを選択します。Lightshot が起動中なら、終了する前に確認します。
4. 完了後、スタートメニューから **Lightshot HDR Fix** を起動します。デスクトップのショートカット作成と完了時の起動は任意です。

インストーラー **0.3.0** は、現在のユーザー用のローカルフォルダーに Lightshot をコピーし、**そのコピーだけを変更**します。元のインストールは保持され、Windows の自動起動設定も自動変更しません。戻すには修正版を閉じて元の版を起動します。ホットキー、設定、ミューテックスを共有する場合があるため、同時に複数を起動しないでください。

> インストーラーとアドオンは未署名です。SmartScreen が警告を表示する場合があります。実行前に、このリポジトリの Releases から取得したことを確認してください。

## 対応環境と制限

Windows 10/11 と DXGI 1.5 対応 GPU が必要です。x86 Lightshot のフォルダー **5.5.0.7**、実行ファイルのバージョンリソース **5.5.0.4**、完全一致するファイルハッシュが必須です。他の版は拒否します。**Lightshot 本体は同梱しません。** 出力は SDR で、画面の HDR はオンのままです。

排他的フルスクリーン、保護されたコンテンツ、回転した画面、編集・保存・クリップボードの一連の操作は追加検証が必要です。失敗時の GDI フォールバックでは露出過多が残ることがあります。カーソルが二重に表示される場合があります。

## 条件を管理した比較

![管理されたグレーパッチテスト](../assets/gray-patches.svg)

**ゲームのスクリーンショットではなく**、管理されたグレーパッチのテストです。元の出力 **210 / 255 / 255 / 255** に対し、修正後は **118 / 240 / 250 / 253**。ハイライトの差を残すためトーンカーブが変わります。あらゆる環境での色の一致を示すものではありません。

1 台の RTX 5080 環境（3440×1440 HDR + 1920×1080 SDR）で、コア全体のキャプチャはウォーム時 **62–78 ms**、初回は約 **312 ms**。操作から表示までの総遅延を保証する数値ではありません。[検証と制限](../VALIDATION.md)。

## 手動 ZIP とビルド

ZIP は上級者向けの代替方法で、Python 3.10+ が必要です。[コマンド、ハッシュ、技術情報は英語の README を参照してください](../../README.md#manual-zip-installation)。

Skillbrains とは公式な関係のない独立プロジェクトで、Lightshot の非公開コアを再コンパイルしたものではありません。新規コードの一般的なオープンソースライセンスは未選択です。サードパーティーのコンポーネントはそれぞれのライセンスに従います。
